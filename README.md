# 🧾 สมุดเก็บรายจ่ายของฉัน

เว็บแอปหน้าเดียวสำหรับเก็บรายจ่าย: **อัปโหลดรูปใบเสร็จ → อ่านข้อความด้วย OCR (ไทย + อังกฤษ) →
ดึงวันที่ / ชื่อร้าน / ยอดเงิน / หมวดออกมาให้อัตโนมัติ → บันทึกเป็นสรุปรายจ่ายรายเดือน**

ทุกอย่างทำงานในเบราว์เซอร์ของคุณเอง ไม่มีเซิร์ฟเวอร์ ไม่มีการอัปโหลดรูปหรือข้อความออกไปที่ไหน
ข้อมูลถูกเก็บใน `localStorage` ของเครื่องคุณ

## ความสามารถ

- **อ่านใบเสร็จอัตโนมัติ** — ลาก-วางรูป, เลือกไฟล์, ถ่ายรูปจากมือถือ, หรือวาง (Ctrl+V) ได้ทีละหลายใบ
  ระบบใช้ [Tesseract.js](https://tesseract.projectnaptha.com/) อ่านข้อความภาษาไทย–อังกฤษในเครื่อง
- **ให้ iPhone ดึงใบเสร็จจากอัลบั้มมาให้เอง** — เว็บแอปเปิดอัลบั้มรูปเองไม่ได้ (เบราว์เซอร์ห้ามไว้)
  แต่แอป Shortcuts ทำได้ จึงรับข้อความใบเสร็จผ่าน `#slip=<ข้อความ>` ได้
  ให้คำสั่งลัด ค้นหารูปภาพ (Find Photos) → แยกข้อความออกจากรูปภาพ (Extract Text from Image) → เปิด URL มาที่แอป
  แล้วแอปจะแยกวันที่/ยอด/ร้านให้เป็นการ์ดรอบันทึกทันที · ส่งหลายใบพร้อมกันได้โดยคั่นด้วย `###SLIP###`
  (ไม่ใช้เส้นขีดเป็นตัวคั่น เพราะสลิปหลายแบบมีเส้นขีดคั่นอยู่ข้างในอยู่แล้ว)
  · ระบุสมุดปลายทางได้ด้วย `#book=<ชื่อสมุด>&slip=<ข้อความ>` (ถ้าไม่ระบุจะเข้าสมุดที่กำลังใช้อยู่)
  · ใช้ `#` ไม่ใช่ `?` ข้อความจึง **ไม่ถูกส่งไปที่เซิร์ฟเวอร์** · วิธีตั้งค่าอยู่ในแอปแล้ว (แท็บเพิ่มรายจ่าย)
  พร้อมช่องเลือกสมุดและปุ่มคัดลอกลิงก์ที่ประกอบให้เสร็จ
- **ดึงข้อมูลให้เอง** — วันที่ (รองรับ พ.ศ. เช่น `14/02/2567`, `1 ธ.ค. 2567`, `15 Jan 2025`),
  ยอดที่ต้องจ่าย (ให้น้ำหนักบรรทัด "รวมทั้งสิ้น / ยอดสุทธิ / ยอดรวม / Total" มากกว่า "เงินสด"
  และข้ามบรรทัด VAT / เงินทอน / ส่วนลด), ชื่อร้าน, และเดารายการย่อยกับหมวดค่าใช้จ่าย
- **รองรับสลิปโอนเงินจากแอปธนาคาร** — จับ "ร้าน/ผู้ขาย" จากปลายทางที่โอนไป (โอนไปยัง / ผู้รับเงิน / ร้านค้า)
  ไม่ใช่หัวสลิป, ดึงยอดจาก "จำนวนเงิน" โดยข้ามค่าธรรมเนียมและรหัสอ้างอิง, และดึงช่อง "บันทึกช่วยจำ" ของสลิปมาให้
  รวมถึงสลิป **จ่ายบิล** ที่ผู้รับเป็นชื่ออังกฤษอย่าง `THAILANDPOST QR PAYMENT` ก็จับได้ ไม่ไปเอาชื่อผู้จ่าย
- **วันที่** ยึดบรรทัดที่มีป้ายกำกับ (วันที่ทำรายการ / วันที่โอน / วันที่) ก่อนเลขอื่นที่หน้าตาคล้ายวันที่
  รองรับปี พ.ศ. สองหลักด้วย (`4 ก.ย. 69` → 2026-09-04)
- **ทนการอ่านเพี้ยนของ OCR** — เทียบคำที่โครงพยัญชนะและยอมให้ต่างกันได้ 1 ตัว
  จึงยังจับคำได้แม้ OCR อ่านเป็น `ขำนวนเงน` (จำนวนเงิน) หรือ `ปันทึกชวยจำ` (บันทึกช่วยจำ)
  ส่วนคำสั้นๆ (โครงพยัญชนะไม่ถึง 4 ตัว) ต้องตรงตัวเต็ม ไม่งั้นป้าย `ถึง` จะไปตรงกับชื่อร้าน `ถุงเงิน`
- **ชื่อเดือนไทยที่อ่านเพี้ยน** — `กุย` `ก,ย,` `ก:ย:` `กันย.` ยังรู้ว่าเป็น ก.ย. ทั้งหมด
  โดยเทียบที่โครงพยัญชนะและชื่อเต็มที่ถูกตัดท้าย แต่ยังแยก ม.ค. กับ มี.ค. ออกจากกันได้
- **อ่านสองรอบเมื่อจำเป็น** — รอบแรกใช้ PSM 6 ซึ่งอ่านสลิปแบบสองคอลัมน์ได้ดีที่สุด
  ถ้าได้ข้อมูลไม่ครบจะอ่านซ้ำด้วย PSM 4 แล้วรวมผล เพราะบางสลิปวางยอดเงินเป็นตัวเลข
  ก้อนใหญ่กลางหน้า ซึ่งโหมดแรกจะข้ามไป
- **แก้ไขก่อนบันทึกได้เสมอ** — OCR ไม่มีวันแม่น 100% ทุกช่องจึงแก้ได้ พร้อมกดดูข้อความดิบที่อ่านได้
- **กดรูปใบเสร็จเพื่อขยายดู** — ทั้งใบที่รออ่านและรายการที่บันทึกไว้แล้ว ใบที่ยังอยู่ในคิวจะขยาย
  ด้วยไฟล์ต้นฉบับความละเอียดเต็ม จึงซูมอ่านตัวเลขเทียบกับที่ระบบอ่านได้
- **อ่านไม่ผ่านก็ไปต่อได้** — ถ้ารอบแรกล้ม ระบบจะลองใหม่อัตโนมัติด้วยรูปที่เล็กลง (กันเครื่องหน่วยความจำน้อย)
  ถ้ายังไม่ได้จะบอกสาเหตุที่เข้าใจได้พร้อมรายละเอียด และมีปุ่ม “ลองอ่านใหม่” กับ “กรอกเอง” ให้เสมอ
- **สรุปรายจ่าย** — ยอดรวมรายเดือน, เทียบกับเดือนก่อน, จำนวนรายการ, เฉลี่ยต่อรายการ,
  กราฟแยกตามหมวด, แนวโน้ม 6 เดือนล่าสุด และร้านที่จ่ายมากที่สุด
- **สรุปรายจ่ายรายวัน** — แท่งกราฟทุกวันของเดือนที่เลือก วันนี้ถูกเน้นสี วันที่ยังมาไม่ถึงจางลง
  พร้อมยอดรวม, ค่าเฉลี่ยต่อวัน (หารด้วยวันที่ผ่านมาแล้วจริง ไม่ใช่ทั้งเดือน), ยอดของวันนี้,
  จำนวนวันที่มีรายจ่าย และอันดับ 3 วันที่จ่ายมากที่สุด
  · **กรองเฉพาะหมวดที่สนใจได้** เช่น ดูว่าค่าอาหารตกวันละเท่าไหร่ โดยไม่กระทบตัวเลขสรุปส่วนอื่น
- **ลูกหนี้ — ออกให้เพื่อนก่อนแล้วหารกัน** ตอนบันทึกรายจ่าย เปิด “➗ หารกับเพื่อน / ออกให้ก่อน”
  ใส่จำนวนคนแล้วกด “แบ่งเท่ากัน” หรือใส่ยอดของแต่ละคนเอง · แท็บ **ลูกหนี้** รวมยอดค้างรายคน
  กด “รับเงินแล้ว” ทีละรายการหรือ “รับครบแล้ว” ทั้งคนก็ได้ · มีป้ายยอดค้างบนแท็บและบนการ์ดรายการ
  ยอดรายจ่ายยังนับเต็มจำนวนที่จ่ายจริง ส่วนหน้าสรุปจะบอกว่าออกให้เพื่อนไปเท่าไหร่และหักแล้วเหลือเท่าไหร่
- **งบประมาณรายเดือน + เตือนเมื่อใช้เกิน** — ตั้งงบรวมต่อเดือน และตั้งงบรายหมวดเพิ่มได้
  หน้าสรุปจะแสดงแถบความคืบหน้า ยอดคงเหลือ และค่าเฉลี่ยที่ใช้ได้ต่อวันในวันที่เหลือของเดือน
  เมื่อใช้ถึง 80% จะขึ้นเตือน "ใกล้เต็มงบ" และเมื่อเกินงบจะขึ้นเตือน "ใช้เกินงบ" ทั้งตอนบันทึกรายจ่าย
  และเป็นแบนเนอร์ค้างไว้บนหน้าแรก · หมวดที่ใช้เกินงบจะถูกทำเครื่องหมายในกราฟแยกหมวด
- **หมวดค่าใช้จ่าย 14 หมวด** — อาหาร · ของใช้/ซูเปอร์ · เดินทาง · ค่าน้ำ/ค่าไฟ · ค่าห้องพัก/คอนโด ·
  ค่าผ่อนรถยนต์ · ค่าบัตรเครดิต · บิล & ค่าบริการ · สุขภาพ · ช้อปปิ้ง · ค่าหวย/ล็อตเตอรี่ ·
  ครอบครัว · เงินยืม · บันเทิง
- **เดาหมวดให้เอง** — จากชื่อร้านและบันทึกช่วยจำ โดยให้น้ำหนักสองส่วนนี้มากกว่าข้อความอื่นในใบเสร็จ
  และคำที่เจาะจงกว่าชนะคำกว้าง ๆ (`ค่าน้ำมัน` ชนะ `น้ำ`) ที่สำคัญคือ **จำหมวดที่คุณเคยเลือกให้ร้านนั้น**
  ครั้งต่อไปที่เจอร้านเดิมจะใส่หมวดเดิมให้เลย ถ้าเลือกหมวดเองแล้วระบบจะไม่เปลี่ยนทับ
- **กันบันทึกซ้ำ** — ถ้าสแกนสลิปใบเดิมซ้ำ (เลขที่รายการเดียวกัน) หรือมีรายการวันเดียวกัน
  ยอดเท่ากัน ร้านเดียวกันอยู่แล้ว จะเตือนก่อนบันทึก และปุ่ม "บันทึกทั้งหมด" จะข้ามใบที่ซ้ำให้เอง
- **มีได้หลายสมุด** — แยกเป็นสมุดส่วนตัว / สมุดร้าน / สมุดบ้าน ได้ตามใจ สลับสมุดจากแถบด้านบน
  แต่ละสมุดมีรายการ งบประมาณ และสรุปของตัวเองแยกกันหมด เพิ่ม / เปลี่ยนชื่อ / ลบสมุดได้ในปุ่ม "จัดการสมุด"
  (ลบสมุดแล้วรายการในสมุดนั้นจะถูกลบไปด้วย และต้องเหลืออย่างน้อย 1 สมุดเสมอ)
- **แท็บเพื่อน 👥 + บัตรของฉันพร้อม QR** — อีเมลที่ล็อกอินคือรหัสประจำตัวของคุณ แท็บเพื่อนมี
  “บัตรของฉัน” แสดง QR ให้เพื่อนใช้กล้องมือถือสแกนแล้วเปิดลิงก์ `#addfriend=อีเมล&name=ชื่อเล่น`
  แอปจะถามยืนยันแล้วเพิ่มคุณเข้ารายชื่อเพื่อนของเขาให้ทันที (ตั้งชื่อเล่นที่เพื่อนจะเห็นได้ในบัตร)
  ไม่มีกล้องก็กด “📤 แชร์ลิงก์เพิ่มเพื่อน” ส่งทางแชต หรือฝั่งรับกด “📋 วางลิงก์” / พิมพ์อีเมลเพิ่มเอง
  รายชื่อเพื่อนบอกยอดค้างระหว่างกันทั้งสองทาง (QR สร้างในเครื่องด้วย `assets/vendor/qrcode.js` ไม่ส่งข้อมูลออกไปไหน)
- **เพื่อนแบบสองทาง** — เพิ่มเพื่อนฝั่งเดียวพอ พอเพื่อนซิงก์ครั้งถัดไป เขาจะเห็นคุณในรายชื่อของเขาเองด้วย
  (พร้อมชื่อเล่นจากบัตรของคุณ) ถ้าเขาลบคุณออก ระบบจะไม่เพิ่มกลับให้ซ้ำ · ต้องรัน `schema.sql` เวอร์ชัน 41 ขึ้นไป
- **ตัวเลขบนแท็บ** — แท็บลูกหนี้โชว์จำนวนรายการที่ยังค้างชำระ (ทั้งเพื่อนค้างเรา และเราค้างเพื่อน · แตะค้างเพื่อดูยอดเงิน)
  แท็บเพื่อนโชว์จำนวนเพื่อนในรายชื่อ
- **กระดิ่งแจ้งเตือน 🔔** (มุมขวาบน) — ขึ้นตัวเลขเมื่อเพื่อนส่งยอดหนี้มา แจ้งว่าจ่ายแล้ว หรือยืนยันรับเงิน
  แอปเช็กให้เองทุก 2 นาทีขณะเปิดอยู่และทันทีที่กลับมาเปิด · แตะรายการเพื่อไปแท็บลูกหนี้ · เปิดดูแล้วถือว่าอ่านแล้ว
  จำนวนที่ยังไม่อ่านโชว์บน **ชื่อแท็บเบราว์เซอร์** เช่น “(2) สมุดเก็บรายจ่ายของฉัน” และบน **ไอคอนแอปที่ติดตั้งไว้**
  (`setAppBadge` — Chrome/Edge บนเดสก์ท็อป, Android, iOS 16.4+)
- **แจ้งเตือนตอนปิดแอป (Web Push)** — ในกระดิ่งกด “🔔 เปิดแจ้งเตือนตอนปิดแอป” เครื่องนั้นจะได้รับแจ้งเตือน
  แม้ไม่ได้เปิดแอป เมื่อเพื่อนส่งยอดมา แจ้งจ่ายแล้ว ยืนยันรับเงิน หรือแก้ยอด · แตะแจ้งเตือนแล้วเปิดแอปที่กระดิ่ง
  ต้องตั้งค่าฝั่ง Supabase ก่อนหนึ่งครั้ง (ดูหัวข้อ [แจ้งเตือนตอนปิดแอป](#แจ้งเตือนตอนปิดแอป-web-push)) ·
  บน iPhone ต้องเพิ่มแอปไว้ที่หน้าจอโฮมแล้วเปิดจากไอคอนนั้น (iOS 16.4+)
- **หารบิล: เลือกชื่อจากรายชื่อเพื่อนได้** — ช่อง “👥 เลือกเพื่อน” ในแต่ละแถว หรือพิมพ์ชื่อเองก็ได้เหมือนเดิม
  (พิมพ์ชื่อตรงกับเพื่อนในรายชื่อพอดี ระบบจับคู่ให้เอง) คนที่เลือกจากรายชื่อจะ **ถูกส่งใบแจ้งหนี้ให้ทันทีตอนบันทึก**
  โดยไม่ต้องกด “ส่งให้เพื่อน” — เครื่องเพื่อนจะได้กระดิ่งแจ้งเตือน · แก้ยอดทีหลังใบแจ้งหนี้ที่ยังรอจ่ายก็อัปเดตตาม
- **ส่งยอดหนี้ให้เพื่อนได้จริง** — เลือกเพื่อนจากรายชื่อ แล้วกด “📨 ส่งให้เพื่อน” ในแท็บลูกหนี้
  เพื่อนที่ใช้เว็บนี้และล็อกอินด้วยอีเมลนั้นจะเห็นหัวข้อ **“หนี้ที่ฉันต้องจ่าย”** ในเครื่องของเขาเอง
  กด “จ่ายแล้ว” พร้อมข้อความตอบกลับได้ · ฝั่งเราเห็นสถานะและกด “ยืนยันได้รับ” เพื่อตัดยอดค้างในรายการจริง
  ฝั่งลูกหนี้กด **“📥 บันทึกเป็นรายจ่าย”** เพื่อเอาส่วนที่ต้องจ่ายลงสมุดของตัวเอง (นับในรายการ/สรุป/งบ
  ใช้ชื่อร้านและวันที่จากใบแจ้งหนี้ เดาหมวดให้ กันบันทึกซ้ำ)
  ยอดค้างทั้งสองทาง (เพื่อนค้างเรา / เราค้างเพื่อน) แสดงเป็นป้ายบนแท็บ
- **จัดการรายการ** — ค้นหา / กรองตามหมวดและเดือน / แก้ไข / ลบ
- **ส่งออกข้อมูล** — ดาวน์โหลด CSV (เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน) และสำรอง/กู้คืนเป็นไฟล์ JSON
- **ล้างข้อมูลได้เมื่อต้องการเริ่มใหม่** — ปุ่ม “🧹 ล้างข้อมูลในเครื่อง” ในแท็บรายการ (ถามซ้ำสองครั้ง
  และเลือกได้ว่าจะล้างธีม/รูปพื้นหลังกับออกจากระบบด้วยไหม) · ฝั่งเซิร์ฟเวอร์ใช้
  [`supabase/reset.sql`](supabase/reset.sql) ซึ่งมีให้เลือกทั้งลบเฉพาะข้อมูล ลบเฉพาะบัญชีเดียว
  รื้อตารางสร้างใหม่ และลบบัญชีผู้ใช้
- **แต่งพื้นหลังเองได้** — กดปุ่ม 🎨 เลือกรูปจากเครื่องมาเป็นพื้นหลัง หรือเลือกชุดสีสำเร็จรูป
  (มินต์ · พระอาทิตย์ · ท้องฟ้า · ชาเขียว) ปรับได้สามอย่าง: ความจางของพื้นหลัง, ความเบลอ
  และ **ความทึบของการ์ด (20–100%)** — ลดความทึบแล้วการ์ดจะกลายเป็นกระจกฝ้า มองเห็นรูปทะลุขึ้นมาทั้งหน้า
  และ **ฝ้าหลังการ์ด (0–40px)** — ตั้ง 0 คือเห็นรูปชัดทะลุการ์ดไปเลย ตั้งสูงคือกระจกฝ้าแบบเบลอ
  เมื่อการ์ดโปร่งกว่า 70% ระบบจะเพิ่มเงาใต้ตัวอักษรและยกสีตัวหนังสือที่จางขึ้นมาหนึ่งขั้นให้เอง
  ระหว่างปรับ กล่องตั้งค่าจะไม่บังหน้าจอ จึงเห็นผลทันที · รูปถูกย่อและเก็บไว้ในเครื่องนี้เท่านั้น
  โดยเก็บใน **IndexedDB** ไม่ใช่ `localStorage` เพราะ Safari บน iPhone ให้พื้นที่ `localStorage`
  แค่ราว 5 MB และนับเป็น UTF-16 (2 ไบต์ต่อตัวอักษร) รูปพื้นหลังจึงใส่ไม่ลงบน iOS ทั้งที่ลงได้บน Android
  ถ้าเครื่องไหนใช้ IndexedDB ไม่ได้ ระบบจะย่อรูปลงเรื่อยๆ จนเขียนลงที่เก็บสำรองได้จริง
- **ไอคอนประจำหมวด** — ทุกหมวดมีไอคอนของตัวเอง เห็นในช่องเลือกหมวด รายการ กราฟ และการตั้งงบ
- **เพิ่มลงหน้าจอโฮมได้เหมือนแอป** — มีไอคอนของตัวเอง (`apple-touch-icon` แบบ PNG สำหรับ iOS
  ซึ่งไม่รองรับไอคอน SVG) และ `manifest.webmanifest` สำหรับ Android/Chrome พร้อมไอคอนแบบ maskable
  เปิดแล้วแสดงเต็มจอไม่มีแถบเบราว์เซอร์ ชื่อบนหน้าจอโฮมคือ “สมุดรายจ่าย”
- ใช้ได้ทั้งบนมือถือและคอม รองรับธีมสว่าง/มืด และเคารพการตั้งค่า “ลดการเคลื่อนไหว” ของเครื่อง

## ซิงก์ข้ามเครื่องด้วย Supabase (ไม่บังคับ)

เปิดใช้แล้วรายจ่ายและงบประมาณจะซิงก์ระหว่างมือถือกับคอมให้อัตโนมัติ โดย **รูปใบเสร็จไม่ถูกอัปโหลด**
ยังเก็บอยู่ในเบราว์เซอร์ของแต่ละเครื่องเท่านั้น ถ้าไม่ตั้งค่า แอปจะทำงานแบบเก็บในเครื่องล้วนเหมือนเดิม

ตั้งค่าสามขั้น (ทำครั้งเดียว):

1. **สร้างตาราง** — เปิด Supabase → SQL Editor → วางไฟล์ [`supabase/schema.sql`](supabase/schema.sql) ทั้งไฟล์ → Run
   (สร้างตาราง `books` / `expenses` / `budgets` / `friends` / `debt_claims`
   พร้อมเปิด Row Level Security ให้แต่ละคนเห็นเฉพาะข้อมูลตัวเอง — ยกเว้นใบแจ้งหนี้ที่ลูกหนี้เห็นเฉพาะใบที่ส่งถึงอีเมลตัวเอง
   และมี trigger กันไม่ให้ลูกหนี้แก้ยอดเงิน แก้ได้แค่สถานะกับข้อความตอบกลับ)

   > **ถ้าเคยรันไฟล์นี้ไปแล้ว ให้รันซ้ำอีกครั้ง** ไฟล์นี้รันซ้ำได้ไม่พัง —
   > เวอร์ชัน 20 เพิ่มตาราง `books` กับคอลัมน์ `book_id` (จำเป็นสำหรับหลายสมุด),
   > เวอร์ชัน 31 เพิ่มคอลัมน์ `split` ให้ `expenses` (จำเป็นสำหรับข้อมูลลูกหนี้)
   > เวอร์ชัน 38 เพิ่มตาราง `friends` กับ `debt_claims` (จำเป็นสำหรับการส่งยอดหนี้ให้เพื่อน)
   > และเวอร์ชัน 41 เพิ่มคอลัมน์ `owner_email`/`owner_name` กับสิทธิ์อ่านให้ `friends` (จำเป็นสำหรับเพื่อนแบบสองทาง)
   > ถ้ายังไม่รัน แอปยังซิงก์รายจ่ายได้ตามปกติ แค่ระบบเพื่อนจะยังใช้ไม่ได้และจะมีข้อความบอกไว้

   > **ข้อมูลแยกตามบัญชีเสมอ** — ถ้าเครื่องเดียวกันสลับไปล็อกอินอีกบัญชี แอปจะหยุดซิงก์แล้วถามก่อน
   > ว่าจะ *ล้างข้อมูลในเครื่องแล้วดึงของบัญชีใหม่* หรือ *ย้ายข้อมูลในเครื่องเข้าบัญชีใหม่*
   > จึงไม่มีทางที่ข้อมูลของสองบัญชีจะปนกัน
2. **ตั้งค่าลิงก์กลับ** — Authentication → URL Configuration → ใส่ **Site URL** เป็น URL ของเว็บคุณ
   เช่น `https://ampaypay.onrender.com` เพื่อให้ลิงก์ยืนยันในอีเมลพากลับมาที่แอป
3. **ใส่คีย์** — คัดลอก Project URL และ publishable key (anon) จาก Settings → API มาใส่ใน
   [`assets/config.js`](assets/config.js)

### แจ้งเตือนตอนปิดแอป (Web Push)

ทำครั้งเดียวจากหน้าเว็บ Supabase ไม่ต้องติดตั้งอะไรในเครื่อง:

1. **รัน `supabase/schema.sql` ซ้ำ** (SQL Editor) — เพิ่มตาราง `push_subscriptions`
2. **สร้าง Edge Function** — Edge Functions → *Deploy a new function* → *Via Editor* → ตั้งชื่อ `push-notify`
   - วางเนื้อหา [`supabase/functions/push-notify/index.ts`](supabase/functions/push-notify/index.ts) ลงในไฟล์ `index.ts`
   - เพิ่มไฟล์ที่สอง `webpush.ts` แล้ววางเนื้อหา [`supabase/functions/push-notify/webpush.ts`](supabase/functions/push-notify/webpush.ts)
   - ปิด **Verify JWT** ของฟังก์ชันนี้ (เราใช้รหัสลับ `x-webhook-secret` แทน) แล้วกด Deploy
3. **ใส่ Secrets** — Edge Functions → Secrets:

   | ชื่อ | ค่า |
   |------|-----|
   | `VAPID_PUBLIC_KEY` | คีย์สาธารณะ ตัวเดียวกับ `vapidPublicKey` ใน `assets/config.js` |
   | `VAPID_PRIVATE_KEY` | คีย์ลับคู่กัน (ห้ามใส่ในเว็บ) |
   | `VAPID_SUBJECT` | `mailto:อีเมลของคุณ` |
   | `WEBHOOK_SECRET` | รหัสลับที่ตั้งเอง (ยาวๆ สุ่มๆ) |

4. **สร้าง Database Webhook** — Database → Webhooks → *Create a new hook*
   - Table `debt_claims` · Events **Insert** และ **Update**
   - Type *Supabase Edge Functions* → เลือก `push-notify`
   - HTTP Headers เพิ่ม `x-webhook-secret` = ค่าเดียวกับ `WEBHOOK_SECRET`
5. ในแอป เปิดกระดิ่ง 🔔 → กด **“🩺 ตรวจการตั้งค่า”** จะบอกว่าตาราง / ฟังก์ชัน / secrets ข้อไหนยังไม่พร้อม
   แล้วกด “เปิดแจ้งเตือนตอนปิดแอป” บนเครื่องที่อยากให้เด้ง

การทำงาน: เบราว์เซอร์สมัครรับ push กับผู้ให้บริการของมันเอง แล้วแอปจด endpoint ไว้ในตาราง `push_subscriptions`
(เห็นได้เฉพาะเจ้าของแถว) · เมื่อมีการเพิ่ม/แก้ `debt_claims` เว็บฮุกเรียก `push-notify` ซึ่งเลือกผู้รับ
(ลูกหนี้ตาม `to_email` หรือเจ้าหนี้ตาม `from_user`) เข้ารหัสข้อความตาม RFC 8291 และลงชื่อ VAPID ด้วย WebCrypto ล้วน
(ไม่พึ่ง npm) แล้วส่งไปที่ endpoint ของแต่ละเครื่อง · endpoint ที่ตอบ 404/410 จะถูกลบทิ้ง · `sw.js` ที่หน้าเว็บลงทะเบียนไว้
ทำหน้าที่รับ push อย่างเดียว ไม่แคชไฟล์ จึงไม่กระทบการอัปเดตเวอร์ชัน

**สร้างคู่คีย์ VAPID ใหม่** (ถ้าอยากใช้คีย์ของตัวเอง) — รันใน Node:
```
node -e "const c=require('crypto'),k=c.generateKeyPairSync('ec',{namedCurve:'prime256v1'}),p=k.publicKey.export({format:'jwk'}),q=k.privateKey.export({format:'jwk'}),b=s=>Buffer.from(s,'base64url');console.log('public:',Buffer.concat([Buffer.from([4]),b(p.x),b(p.y)]).toString('base64url'));console.log('private:',q.d)"
```
แล้วใส่ public ใน `assets/config.js` และทั้งคู่ใน Secrets

### วิธีล็อกอิน

แอปรองรับสองแบบ เลือกใช้ได้ในกล่อง ☁️

**1. อีเมล + รหัสผ่าน (ค่าเริ่มต้น — ไม่ต้องพึ่งอีเมลเลย)**
ครั้งแรกใส่อีเมลกับรหัสผ่านที่ต้องการแล้วกด "สมัครใหม่" เครื่องอื่นใช้อีเมล/รหัสผ่านเดิมเพื่อเห็นข้อมูลชุดเดียวกัน

> ถ้าอยากให้สมัครแล้วเข้าใช้ได้ทันทีโดยไม่ต้องยืนยันอีเมล: Authentication → Providers → Email →
> ปิดสวิตช์ **Confirm email** (สำหรับสมุดรายจ่ายส่วนตัวถือว่าเพียงพอ เพราะข้อมูลถูกกันด้วย RLS อยู่แล้ว)

**2. ส่งลิงก์ทางอีเมล** — ใส่อีเมลแล้วกดลิงก์ในอีเมล ต้องตั้ง Site URL ตามข้อ 2 ด้านบนก่อน

### อยากได้รหัส 6 หลักในอีเมล

Supabase จะยอมให้แก้เทมเพลตอีเมล **ต่อเมื่อตั้งค่า SMTP ของตัวเองแล้วเท่านั้น** (เช่น Resend, Brevo, Gmail)
ถ้ายังใช้อีเมลของ Supabase หน้าเทมเพลตจะล็อกไว้ แก้ไม่ได้

ตั้ง SMTP เสร็จแล้วไปที่ Authentication → Emails → **Magic Link** แล้วใส่ `{{ .Token }}` ลงในเนื้ออีเมล เช่น

```html
<h2>เข้าสู่ระบบสมุดเก็บรายจ่าย</h2>
<p>รหัสเข้าใช้งานของคุณคือ</p>
<p style="font-size:28px;letter-spacing:6px;font-weight:bold">{{ .Token }}</p>
<p>รหัสมีอายุ 1 ชั่วโมง</p>
<p>หรือกดลิงก์นี้เพื่อเข้าใช้งานทันที: <a href="{{ .ConfirmationURL }}">เข้าสู่ระบบ</a></p>
```

แอปรองรับทั้งสองแบบ: ใส่รหัสในช่อง หรือกดลิงก์ในอีเมลแล้วกลับมาที่แอปโดยล็อกอินให้เลย

การใช้งาน: กดปุ่ม ☁️ มุมขวาบน → ใส่อีเมล → รับรหัส/ลิงก์ทางอีเมล → ล็อกอิน
หลังจากนั้นแอปจะซิงก์ให้เองทุกครั้งที่บันทึก แก้ไข หรือลบรายการ และกด "ซิงก์ตอนนี้" เองก็ได้

**ข้อควรรู้เรื่องคีย์:** publishable key (anon) ออกแบบมาให้ฝังในหน้าเว็บได้ ความปลอดภัยมาจาก
Row Level Security ในฐานข้อมูล ห้ามนำ `service_role` key มาใส่ในโค้ดฝั่งเว็บเด็ดขาด

## วิธีใช้งาน

เป็นไฟล์สแตติกล้วน ไม่ต้อง build ไม่มี dependency ที่ต้องติดตั้ง

```bash
git clone https://github.com/bmsjib5-ux/AmPayPay.git
cd AmPayPay
python3 -m http.server 8000     # หรือ npx http-server -p 8000
# เปิด http://localhost:8000
```

> แนะนำให้เปิดผ่าน http(s) ไม่ใช่ดับเบิลคลิกไฟล์ (`file://`) เพราะตัวอ่าน OCR ทำงานผ่าน Web Worker
> ถ้าจะเอาขึ้นออนไลน์ อัปโหลดทั้งโฟลเดอร์ขึ้น GitHub Pages / Netlify / Vercel ได้เลย

### ขึ้นออนไลน์ด้วย Render (ฟรี)

รีโปนี้มี [`render.yaml`](render.yaml) ให้แล้ว Render จะตั้งค่าเป็น Static Site ให้อัตโนมัติ

1. ล็อกอิน [dashboard.render.com](https://dashboard.render.com) แล้วเชื่อมบัญชี GitHub
2. กด **New +** → **Static Site** → เลือกรีโป `bmsjib5-ux/AmPayPay`
3. เลือก Branch ที่ต้องการ deploy (เช่น `main` หรือ `claude/expense-tracker-app-ctofm0`)
   - **Build Command:** เว้นว่างไว้ได้เลย
   - **Publish Directory:** `.`
4. กด **Create Static Site** รอสัก 1 นาที จะได้ URL หน้าตา `https://<ชื่อที่ตั้ง>.onrender.com`

ทุกครั้งที่ push ขึ้นแบรนช์นั้น Render จะ deploy ใหม่ให้เอง
(ทางเลือกอื่นที่ไม่ต้องสมัครอะไรเพิ่ม: เปิด GitHub Pages จาก Settings → Pages ของรีโปนี้)

ครั้งแรกที่อ่านใบเสร็จ เบราว์เซอร์จะดาวน์โหลดตัวอ่าน OCR และชุดภาษาไทย (~5 MB) จาก CDN
แล้วแคชไว้ ครั้งต่อไปเร็วขึ้นและใช้แบบออฟไลน์ได้

### ใช้แบบออฟไลน์เต็มรูปแบบ (ไม่พึ่ง CDN)

ดาวน์โหลดไฟล์ของ Tesseract มาไว้เองแล้วบอกที่อยู่ใน `index.html` ก่อนโหลด `assets/app.js`:

```html
<script>
  window.OCR_PATHS = {
    workerPath: 'vendor/worker.min.js',   // tesseract.js@5/dist/worker.min.js
    corePath:   'vendor/core/',           // tesseract.js-core@5 (ไฟล์ .wasm / .wasm.js)
    langPath:   'vendor/lang'             // tha.traineddata.gz, eng.traineddata.gz
  };
</script>
```

## ข้อควรรู้เรื่องความแม่นของ OCR

- ถ่ายให้ใบเสร็จเต็มกรอบ แสงสม่ำเสมอ ไม่เอียง จะอ่านแม่นขึ้นมาก
- Tesseract มักซอยอักษรไทยเป็นตัวๆ (`ย อ ด ร ว ม`) — ตัวแปลงในโปรเจกต์นี้เชื่อมกลับให้อัตโนมัติ
- ถ้าหายอดไม่เจอ ระบบจะเดาจากตัวเลขทศนิยมที่มากที่สุดในครึ่งล่างของใบเสร็จ และจะขึ้นข้อความเตือนให้ตรวจสอบ
- ข้อมูลอยู่ในเบราว์เซอร์เครื่องเดียว: ล้าง Site data = ข้อมูลหาย จึงควรกด **สำรองข้อมูล** เป็นระยะ
